# 동북권 집찾기 v5 (Vercel)

## 배포
1. 이 폴더를 GitHub에 올리고 Vercel에서 Import (`.env`는 올리지 마세요)
2. Settings > Environment Variables
   - `DATA_GO_KR_SERVICE_KEY` : 공공데이터포털 일반 인증키 (이전 키는 노출됐으니 재발급 권장)
   - `APP_TOKEN` (선택) : 설정하면 앱 첫 조회 때 토큰을 한 번 묻고 기기에 저장. 다른 사람이 API를 쓰지 못하게 막음
3. Redeploy 후 `https://프로젝트.vercel.app` 을 휴대폰 크롬에서 열고 메뉴 > 앱 설치

## 필요한 활용승인
아파트 매매 실거래가(기본·상세), 아파트 전월세 실거래가 — 전월세 미승인이면 매매만 표시되고 안내문이 뜹니다.

## 동작
- 단지명 → 12개 시군구에서 최근 3개월 매매로 탐색, 동명 단지는 선택
- 해제 거래 제외, 전세는 월세 0원·갱신계약 제외, 최근 3건 중앙값 사용
- 응답은 성공 시에만 6시간 캐시(호출 한도 절약)
