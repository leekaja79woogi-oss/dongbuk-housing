앱 열고 설치하기

안드로이드 설치

  1. 이 링크를 Chrome에서 열어주세요.
  2. 위의 앱 열고 설치하기를 누르세요.
  3. Chrome 오른쪽 위 ⋮ → 홈 화면에 추가 → 설치를 선택하세요. 메뉴에 ‘설치’가 없다면 ‘바로가기 만들기’를 선택하세요.

아이폰 설치

  1. 이 링크를 Safari에서 열어주세요.
  2. 위의 앱 열고 설치하기를 누르세요.
  3. 공유 버튼 → 홈 화면에 추가 → 추가를 선택하세요.

QR코드로 공유

카카오톡 등 앱 안에서 열었다면 메뉴에서 ‘다른 브라우저로 열기’를 선택해주세요. 설치 후 홈 화면에서 실행할 수 있으며, 실거래 조회에는 인터넷 연결이 필요합니다.
